# Runtime dependencies for the ESET SOC Lite platform.

# checkout is tested against. Present because Railway/Nixpacks installs from

#
# Dev/test extras are deliberately not here — see [project.optional-dependencies]
# in pyproject.toml, or install with: pip install -e ".[dev]"
